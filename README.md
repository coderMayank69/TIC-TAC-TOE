# TIC-TAC-TOE

A classic Tic-Tac-Toe game built with web technologies.

## Overview

This is an interactive Tic-Tac-Toe game implemented using vanilla JavaScript, HTML, and CSS. Play against another player or test your strategy skills with this timeless game.

## Features

- **Interactive Gameplay**: Click to make your moves on the game board
- **Two-Player Mode**: Play with another person on the same device
- **Game Status Display**: Real-time feedback on whose turn it is and game outcomes
- **Reset Functionality**: Start a new game anytime
- **Responsive Design**: Works on various screen sizes

## Technology Stack

- **JavaScript** (43.8%) - Game logic and interactivity
- **CSS** (31.4%) - Styling and layout
- **HTML** (24.8%) - Page structure and markup

## How to Play

1. Open the game in your web browser
2. Player X goes first, followed by Player O
3. Click on any empty cell to make your move
4. The first player to get three in a row (horizontally, vertically, or diagonally) wins
5. Click the reset button to start a new game

## Installation

No installation required! Simply clone or download this repository and open the HTML file in your web browser.

```bash
git clone https://github.com/coderMayank69/TIC-TAC-TOE.git
cd TIC-TAC-TOE
# Open index.html in your browser
```

## Game Rules

- The game is played on a 3x3 grid
- Players take turns placing their symbol (X or O)
- A player wins by placing three of their symbols in a row:
  - Horizontally
  - Vertically
  - Diagonally
- If all cells are filled and no player has won, the game is a draw
